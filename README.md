# Mixture-of-Hierarchical Experts (MoH)

**Official repository for "Mixture-of-Hierarchical Experts: Optimized Mamba Architecture for Vision Diffusion" (NeurIPS 2026).**

**Yejun Jung, Dongyoon Kim, Jinsun Park**

MoH introduces a timestep-aware hierarchical expert routing mechanism for efficient and effective Mamba-based vision diffusion models.
